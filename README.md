# magic-agent-skills

A factory for my AI coding harness resources: skills, subagents, commands, rules, MCP, hooks. Everything is authored once in [`.rulesync/`](.rulesync) and generated for each harness (Claude Code, opencode) with [Rulesync](https://github.com/dyoshikawa/rulesync).

## Skills

| Skill | What it does |
|-------|--------------|
| [`agents-md-structurer`](.rulesync/skills/agents-md-structurer/SKILL.md) | Restructures the `CLAUDE.md` / `AGENTS.md` generated by `/init` into a lean, consistent agent context file. |

## Subagents

| Subagent | What it does |
|----------|--------------|
| [`code-reviewer`](.rulesync/subagents/code-reviewer.md) | Read-only code reviewer: bugs, security, performance, tests and readability in a diff, with `file:line` evidence. Leaves architecture to `architecture-guardian`. |
| [`architecture-guardian`](.rulesync/subagents/architecture-guardian.md) | Read-only architecture reviewer: checks changes against documented boundaries, layering and dependencies, reports violations with `file:line` evidence. |

## Commands

| Command | What it does |
|---------|--------------|
| [`code-reviewer`](.rulesync/commands/code-reviewer.md) | Reviews the current changes (tracked and untracked) by running `code-reviewer` and `architecture-guardian` in parallel, then merges both reports into comments ranked by severity. |

## Install

### Everything (Rulesync)

Install [Rulesync](https://github.com/dyoshikawa/rulesync) (`npm i -g rulesync` or `brew tap dyoshikawa/rulesync https://github.com/dyoshikawa/rulesync && brew install rulesync`), then from this repo:

```bash
rulesync generate --global
```

This writes skills, subagents, commands, rules, MCP and hooks to `~/.claude/` and `~/.config/opencode/`. Targets and features are set in [`rulesync.jsonc`](rulesync.jsonc). `delete` is off, so existing global files are never removed.

### Without cloning (npx)

```bash
npx magic-agent-skills                                       # everything
npx magic-agent-skills --skill agents-md-structurer          # one skill
npx magic-agent-skills --subagent architecture-guardian      # one subagent
npx magic-agent-skills --command code-reviewer               # one command
npx magic-agent-skills --list                                # what is available
npx magic-agent-skills --dry-run                             # preview, write nothing
```

`--skill`, `--subagent` and `--command` are repeatable. When any is given, only the selected resources are installed. Rulesync is bundled, nothing else to install.

### Skills only (skills CLI)

With the [skills CLI](https://skills.sh):

```bash
npx skills add turchiniaxel/magic-agent-skills                                  # all skills
npx skills add turchiniaxel/magic-agent-skills --skill agents-md-structurer     # one skill
npx skills add turchiniaxel/magic-agent-skills --list                           # list only
```

## Repository layout

```
magic-agent-skills/
├── rulesync.jsonc          # targets + features
├── skills -> .rulesync/skills   # symlink so `npx skills add` finds the skills
└── .rulesync/              # single source of truth
    ├── skills/<name>/SKILL.md
    ├── subagents/<name>.md
    ├── commands/<name>.md
    ├── rules/*.md
    ├── mcp.json
    └── hooks.json
```

Generated output (`.claude/`, `.agents/`, `.opencode/`, ...) is gitignored.

## Adding a resource

- **Skill**: create `.rulesync/skills/<name>/SKILL.md`. `<name>` is kebab-case and matches the frontmatter `name`. Put every "when to use" hint in `description` (1-1024 characters).
- **Subagent**: create `.rulesync/subagents/<name>.md` with `name`, `targets` and `description` frontmatter, then the prompt as body. Per-harness overrides go under `claudecode:` / `opencode:`.
- **Command, rule, MCP, hook**: see the [Rulesync file formats](https://rulesync.dyoshikawa.com/reference/file-formats).

Then add a row to the tables above and run `rulesync generate --global`. Restart the harness: resources are loaded at startup.
